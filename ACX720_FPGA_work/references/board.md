## 器件与外设

- 已验证的 100T 配置：`xc7a100tfgg484-2`，JTAG 名称常见 `xc7a100t_0`；后缀不能仅从 `get_hw_devices` 简名推断，结合已有工程和芯片标识。
- 板载时钟 50 MHz，Y18，通常 LVCMOS33；MMCM/PLL 输出频率由具体工程决定。CPU 80 MHz 和 TFT 约 33 MHz 是一个已验证的示例配置，不是板卡固定系统时钟。
- 8 个用户 LED、8 位拨码、5 个独立按键；拨码/按键上拉、闭合接地；LED 高有效。原理图含电平转换器，不能把输入悬空或按键损坏作为默认诊断。
- DDR3：16 位总线，手册列 256 MiB、1.5 V；具体芯片料号可能随 BOM 变化。使用同器件例程的 MIG 配置及其生成约束/模型，等 `init_calib_complete` 再验读写。
- QSPI Flash：手册列 128 Mbit/16 MiB，型号可能随 BOM 变化。固化前核对实装芯片与 Vivado cfgmem 器件，不能照搬某一个 Flash 型号。
- CH340E USB UART；JTAG 下载器 USB、UART USB 和 FX2 USB 数据接口是不同用途，不能互相当作连接已通的证据。
- 另有 TFT RGB、双 HDMI、OV5640 DVP/SCCB 接口、千兆以太网 RTL8211E、FX2 USB2.0、ES8388 音频、I2C EEPROM/RTC、SD、串行 ADC/DAC、蜂鸣器、红外、74HC595 数码管和扩展 GPIO。电压、方向与 IP 时序按具体接口核对。
- 普通 FPGA IO 的 3.3 V 逻辑不能因为扩展座带 5 V 电源脚就当作 5 V 容忍。

| FPGA_GCLK1 | Y18 | 50 MHz，20 ns |
| LED0～7 | M22 N22 L21 K21 K22 J22 H22 M21 | 高有效，只有 8 个用户 LED |
| SW0～7 | G22 D22 E22 G21 E21 D21 C22 B22 | 上拉；开路=1、闭合=0 |
| S0～4 | F15 A20 B20 A21 B21 | 上拉；松开=1、按下=0 |
| FPGA_UART_RX / TX | J21 / M15 | 以 FPGA 为观察方向 |
| TFT_clk/de/hs/vs/pwm | AB20 / AB22 / V19 / Y19 / AB21 | 具体面板极性与像素时钟另核对 |
| TFT_rgb[15:0] | N14 P16 R17 N15 L6 T18 N17 P17 P15 R16 N13 U17 U18 P14 R14 R18 | 顺序是从 bit15 到 bit0 |

## 原始资料差异

- 管脚表 Sheet1 第 12 行写 `LED8=N19`，第 34 行同一 N19 又是 `BEEP`；用户手册和原理图均只有 LED0～7。将 LED8 标作疑点，不加入默认自动约束信号。
- 摄像头数据/PCLK/HREF/VS 方向在管脚表多处写成 O；对 FPGA 来说它们是输入。表的封装引脚与厂家 ch46 一致，但方向列不能照抄。
- `E_TXC` 等接口方向、HDMI OE 等控制信号的电平标准必须结合原理图/厂家 XDC，不能从相邻差分数据行类推。
- 手册多处以 35T 为描述对象，而资料包实际提供三种容量。型号、资源和 DDR/MIG 配置以当前实例为准。

# 复位与拨码验证示例

一个 CPU + TFT 示例可以用以下分层检查，避免“有静态背景却没有动画”时盲改绘图程序。

1. 仿真默认物理开关输入为全 1，按键松开为 1；同时验证有效操作后的电平。
2. 分开记录高有效 reset 请求和低有效 rst_n 端口，检查端口实际实现。
3. 在锁定信号有效、上电等待结束后，确认 CPU 和显示域都已释放复位。
4. 观察 PC/状态机与 GPIO 心跳，证明程序在执行。
5. 对帧缓冲以 write_enable && data==目标颜色为触发条件，抓真实写入及地址变化。
6. 核对显示选择开关是否把 CPU 帧缓冲切换为硬件彩条，再检查读口、DE 和 RGB。
7. 单独记录配置成功、内部运行和最终可见动画三项结果。

SW0 是否复位、SW1 是否切换彩条是项目自定义功能。板卡的电气事实只有上拉、闭合接地，以及相应封装引脚；不要混淆物理电平和项目功能。

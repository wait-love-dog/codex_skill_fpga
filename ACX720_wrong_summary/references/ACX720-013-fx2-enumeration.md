# ACX720-013：FX2 描述符错误、RAM 下载成功但不能枚举

- 日期/状态：2026-11-07，已解决当前 USB 传图与可见窗口问题；用户确认“画面正常，明显更流畅”。旧固件内部的唯一故障指令/中断原因没有完全分离。
- 环境：ACX720-V3 / xc7a100tfgg484-2，OV5640 RGB565，Windows、Vivado 2019.1，F13。FX2 CY7C68013A，Cypress 签名驱动，高速 EP6 IN 0x86；IFCLK 30 MHz、最小控制固件的 8051 核 12 MHz。
- 起因：F12 电脑显示约 2 fps。UART 1 Mbps / 8N1 每秒最多约 100000 字节，160×120 RGB565 一帧 38400 字节，仅负载就需 384 ms；这是传输带宽约束，不能据此认定 RV 算力不足。USB 数据通过硬件 FIFO，RV 保留控制和报警。
- 现象：接 FX2 数据口后，Windows 报“无法识别 USB 设备”。有时 04B4:00F1 为 Code 28（无匹配驱动），随后 VID0000:PID0002 / Code 43（描述符读取失败）。厂家工具提示 RAM 加载成功后，设备仍重新枚举失败。
- 分层测量：安装厂家签名驱动，只解决驱动绑定；改为电脑直连，仍需区分电气、ROM 引导和固件执行。按住 USB-PG 约 3 秒、轻按并释放 USB-RST、最后释放 USB-PG，可出现 04B4:8613 高速 ROM 引导设备。此时 USB 控制传输可用。
- RAM 验证：旧摄像头伴随固件的对齐镜像有 3248 字节写入并读回一致，但启动后仍描述符失败，因此“下载成功”不等于运行成功。新轮询固件第一次使用未规范化 HEX 记录时在地址 09B9 读回不匹配，加载器拒绝启动并保持 CPU 停止；转换成稠密、16 字节对齐记录后，3238 字节全部读回一致，启动后成功枚举 FPGA Camera / 04B4:00F1 / 高速 512 字节 EP6。
- 失败尝试：旧固件仅把 FIFO 48 MHz 改为 30 MHz、增加断开/重连延时、把主机工具改为 x86，均未单独恢复旧固件枚举。不能把这几个改动之一登记为已经证明的唯一根因。
- 修复：用最小轮询 USB 控制固件取代旧中断框架；描述符按常量段对齐，使用经过逐字节校验的对齐 HEX。厂商附带 Keil 限制版正常编译，代码量在许可范围内，没有绕过限制。高速图像仍由硬件 Slave FIFO 处理。启动脚本识别 ROM 引导态后自动完成临时 RAM 加载和重新枚举核对。
- FPGA 传图：640×480 摄像头下采样到 320×240 RGB565，双行缓存与 1024×16 异步 FIFO，不新增整帧 BRAM。每行包含帧号、时间、行号、头 CRC32 与负载 CRC32；收齐同帧 240 行才交模型，未收全或坏 CRC 的数据丢弃，分析落后时跳过旧的完整帧。
- 回归：Python 27 项通过；Icarus 与 XSIM 的缩小图像、异步时钟、背压、溢出、CRC 和完整帧恢复通过，生产顶层 XSIM 通过。静态插件对参数化子实例展开有限，不能用其零错误证明 CDC 完成。
- 实现：F13 WNS +0.440 ns，WHS +0.043 ns；LUT 9882，FF 6057，BRAM36 117.5/135，DSP 6；FX2 flag 到 SLWR 路径余量 +4.723 ns。JTAG DONE=1、CRC_ERROR=0、USR_ACCESS=ac720f13。整工程仍有既有 CDC/板外 IO 待签核项，新 USB Gray 指针识别为两级 ASYNC_REG 多位同步；没有清除告警来冒充完整签核。
- 实板：纯 USB 441 帧 / 15.016 秒，约 29.37 fps，该次行头/负载 CRC 错误为 0，6 帧不完整被淘汰。背景场景的模型和状态回传 60.016 秒处理 1772 帧，约 29.53 fps、0 整帧超时。后续可见窗口观测有少量 CRC 拒绝和不完整帧，已丢弃，不能宣称零丢包。用户确认画面正常且明显流畅。
- 证据：`fall_detection/evidence/fx2/verified_ram_polled_aligned.json`、`probe_polled_aligned.json`、`live_capture.json`、`build_summary.json`、`acceptance.json`；`runs/usb_live_validation_60s/summary.json`；`tests/tb_fx2_video.sv`、`usb_transport.py`、`fx2/firmware/fx2_camera_poll.c`。
- 限制/复用：旧中断框架、核心时钟与记录布局的单变量因果链尚未完全隔离；当前固件成功是明确版本组合的结论。运行固件不支持的 A0 外设寄存器读取会返回无意义值，不能当实测寄存器状态。只写 FPGA JTAG RAM / FX2 RAM，没有写 Flash/EEPROM，断电需按工作流重新加载。模型准确度、真实人体负载性能、长期可靠性仍要分别验证；USB 迁移也不修复旧 UART 不完整帧问题。

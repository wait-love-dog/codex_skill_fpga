# ACX720-005：共模亮度正弦可通过旧频谱判据

## 已证实的判据缺口

旧离线工具去趋势、选频带最大峰，再要求峰值/频带中位数足够高和 RGB 主峰相近。此组合只说明存在一致周期，不能证明周期来自血容量变化。

数值反例使用 RGB 三通道完全相同的比例亮度正弦，不加入任何色度脉搏。旧工具按既有条件返回成功，输出三通道一致的候选；这并非证明旧 DFT 数值错误，而是说明其返回成功不能用于心率验收或 UI 的“测量成功”状态。

## 改进与验证范围

- 保留旧工具为诊断，明确标注候选未经生理验证；不再把通道不一致绝对解释成“不是脉搏”。
- 新 PC 参考路径比较绿色与 POS 信号，按分段稳定性、原始亮度变化、色度信号、频带集中度、自相关和传输完整性判断；不合格输出 REJECTED，候选值为空。
- POS 实现依据 Wang 等人的 Algorithmic Principles of Remote-PPG；门槛为项目实验设置，不是论文标准。通过时也仅标为未验证候选。
- 合成测试覆盖非 30 Hz 采样的已知脉搏、共模周期、照明阶跃、随机噪声、过亮、错误传输和前后频率变化。已知脉搏可恢复，其余反例拒绝。
- 实际移动/光照干扰的脸颊数据和不稳定手指数据均被拒绝。固定白纸用作非皮肤对照，不能解释为心率样本；纸张与脸部配置不同，不能凭纸张稳定宣布所有配置和光学条件无问题。

这些测试证明相应反例得到处理，不证明能拒绝所有彩色周期灯光或运动伪迹，也不构成人体测量准确度验证。没有同步参考时不能给出“误差小于某 bpm”的结论。

原工程证据：`video/tools/pulse_quality.py`、`video/D6_PC脉搏提取与质量判定.md`、`video/evidence/d5_control_20261101/quality_checks/`。优先维护负对照和拒绝原因，不为单个目标强行调阈值。

## 现场摆位检查补充（2026-11-02）

布置照片提示镜头高度和方向需要单独核对；显示屏朝向用户并不能证明镜头对准皮肤，LED 亮或串口有帧也不能证明 ROI 的物体是皮肤。照片中 LCD 拍得暗同样不足以认定程序已停止，先读实际状态。

用户经预览确认绿框全是脸颊后，短采集的亮度变化较之前明显减小。但记录长度和曝光设置不同，不能据此把先前异常的唯一根因认定为镜头朝向。使用短记录反馈摆位，再决定是否做长记录，可减少无效长时间采样；短记录稳定也不等于有脉搏。

# 新案例填写模板

以下字段用于新案例；以事实填写，未知写“待验证”，不把模板当作已经发生的案例。

- 编号与标题：索引最大编号加一；简述可检索现象。
- 日期与状态：未解决 / 待实板验收 / 已解决；注明最后一次用户反馈。
- 环境与版本：板卡、器件、工具、生产顶层、软件/位流标识、关键时钟和物理开关电平。
- 现象与复现：预期、实际、触发条件；是否同一配置版本；最小复现步骤。
- 假设与测量：每个假设对应能区分它的观测；记录测量范围及结果。
- 失败尝试：改了什么、用户/仪器反馈什么、实际排除了什么；无改善也要保留。
- 根因：已证实因果链；有证据但尚未证实的部分单独列出。
- 修复：最小变化、涉及接口、兼容影响和资源/画质/性能代价。
- 验证：仿真实际覆盖与缩短/绕过项、实现报告、内部板上证据、用户可见验收分别写明。未做的检查不能写 PASS。
- 证据定位：工程相对路径、测试名称、必要的版本标识；不带本机隐私路径。
- 限制与复用：这次证据不能证明什么，下次遇到相似现象优先查什么。

写完同步更新索引。重新验证的结果追加到原案例，不能抹掉先前未通过的反馈。
